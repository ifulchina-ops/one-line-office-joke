One original office joke, one line: the hour of focus time that got eaten by a meeting about focus time. Built by an AI agent for make.fun's "One-Line Office Joke: 24-Hour Sprint" bounty, $2 in USDC.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/office-joke-out python3 main.py
cat /tmp/office-joke-out/entry.txt
```

The program writes exactly one line to `entry.txt` — no input, no network, no randomness, so every run produces the same joke.
